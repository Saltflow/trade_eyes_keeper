# 第二轮：证据、数值和实际图片审查

读取同一冻结证据、第一轮完整稿、图表原数和实际PNG。先核对收到哪些图，不假称审查未见图片。对象数量、行业和比较/参照角色必须与本轮输入相符，不能把模板或旧案例当成公司清单。核对实际历史、同指标同期间同分母、共轴/分面尺度以及版本/并表差异。

复核事实/假设/预测与A/E边界，增长和正常化利润的依据，实际适用的投入、资本留存与融资约束，普通股利润/权益/股数和ROE分母，现金定义与价值分母是否匹配。检查CFO起步重复扣减、利息/税/融资重复处理、分红/回购/留存/终值重复计入、股份摊薄和权益滚动。不能用不适用的行业现金公式强行计算。

检查同一组现金流的IRR、各hurdle最高买价、安全边际、终值贡献和反向条件是否一致，退出假设是否掩盖经营风险，报价日期与未来现金权利/折现时钟是否相容。缺行情或未指定hurdle不取消全部条件估值，虚构算例不能补真实公司缺项。已确认资料覆盖不由局部未定位或空附件推翻。

输出完整自足主题修订稿、全部保留chart数据及简短审查记录。逐项核对推导数字是否存在于冻结计算结果；删除无实际计算支持的手工预测、IRR及买价，不用免责声明保留它们。需要改动模型数值时给返工意见，不能在修订稿中自行重算。实际修订图将在本轮之后重新生成，本轮不能声称看过尚未生成的新图。不修改前阶段、不增加付费轮次。


对照调查交接中的模型源码、输入、来源定位、实际结果与检查回执，复核业务机制和上下游传导。沿通用合同的大类提醒检查遗漏，但由本轮证据决定具体机制。尤其核对历史与预测是否使用相同单位、含税口径和期初/期末基础；约束参数是否实际影响分红、融资及每股结果；自检是否只是校准、恒等式或为了预期方向改参。无法闭合的核心机制限制数值结论的用途，不能因自检全绿而略过。

