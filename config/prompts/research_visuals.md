# 内部工作二：用表格与图表检验并呈现论证

只为关键论证选图：历史经营和每股变化、利润到现金、资本配置、估值敏感性等。先检查可比口径，避免把不同行业总金额当效率排名。已披露数、推算值和假设情景应明确区分；同一图不混合不同单位/币种、平均与期末、原报与重述。无法对齐时分图、分表或保留文字说明，不能为了画图补数。

图表只能引用本次材料的明确数值或正文写明公式及假设的推算。缺值用null，不能用0代替。区间、百分比和文本在正文表格完整保留；只有明确单位后可用于图的数值才写成YAML数字，例如22.51%写数值22.51且unit为%。不要从带单位字符串猜数。图应帮助发现反例；发现矛盾须回到审查和结论修正。

在最终Markdown需要插图的位置写以下形式的chart代码块。只支持line、bar；脚本机械制图，不执行模型代码。每图所有元信息必填，字段含义按示例。x是明示的年度、时点或情景标签，series每组与x等长。source填写所提供的文档名与章节；scope、period_basis、version用简短明文。没有图的必要就不输出chart块，不为满足格式编造图。

```chart
id: cash_conversion
type: line
title: 经营现金流变化（格式示例，数字为虚构，禁止当实际数据）
unit: 亿元
scope: 示例公司；合并
period_basis: 各年度期间总额
version: 示例原报
source: 离线格式示例；非财报事实
x: ['FY2023', 'FY2024', 'FY2025']
series:
  - name: CFO
    values: [10.0, null, 12.0]
```

绘图失败仅意味着该图未生成，文字和原始图表说明仍然交付。写作不依赖脚本猜测修复。若输入含上一轮图表数据，以其原始数值和口径审查，不能依据图片像素推数。
