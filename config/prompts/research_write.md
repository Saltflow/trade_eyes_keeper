# 内部工作四：形成唯一最终报告

仅输出自足的最终研究报告Markdown。先讲中心结论及必要条件，再按业务与估值机制展开证据、关键历史表、图表、反例及限制；结尾列出会推翻判断的事项和后续观察。标题由实际主题决定，保持流畅的连贯论述，不写成七问逐项填空或四阶段工作日志。

图表chart块放在论证需要的位置，图旁明确读图结论和边界。表格行对应项目、列对应实际年度/时点，同表口径集中说明一次，例外分组或脚注。数字不因润色被改变，单位、年份、版本、普通股范围、假设条件和决定性反证不能删掉。图表只是证据表达，不能借图新造结论。

读者应能区分材料中已有判断与本次审查的新结论。引用提供的文档名和章节即可，不建立逐单元格Evidence、原PDF页码追溯或勾稽验收体系。主要冲突及其对结论的影响要留在正文；次要审查注记可集中在短附录。未取得资料与未披露分清，不把传输成功当事实验证。

本次只有一次模型回答：不得编造独立审稿人、工具执行、事实核验或多轮已完成记录。结论、图表和写作应在本次回答内相互检查；确需追加研究的事项列明供用户决定。最终报告是一份完整交付，原始响应和图表数据会被脚本独立归档。
