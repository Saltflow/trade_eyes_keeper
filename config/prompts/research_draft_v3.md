# 第一轮：按主题形成完整比较初稿

先判断同行组和参照组，再提出贯穿全文的估值问题。输出完整、自足的Markdown主题稿，保留共同规模总览、分母与历史，不能依次交三家公司简介。参考已投递的主题排版示例，但不得复制示例中不属于本轮材料的数值。

每个主题执行同一顺序：比较发现 → 同指标历史表 → 共轴比较图 → 差异的业务机制 → 反例及条件。工程两家在同一段落直接对照；白酒作为机制参照嵌在相关主题，不单写成第三篇。无法可比之处说明原因并继续比较其他已知事实。

用完整chart块给出图数据，图例为公司、x为同一实际年份，单位和分母明确。至少考虑增长/回报、利润与现金、占款、资本配置；同一指标优先共图，不每家公司重复一套。绝对金额用于规模，统一基准的指数或比例用于变化和强度，两者不要混成一条轴。

历史表按指标集中列出公司行：例如“营业收入/四川、隧道、泸州参照”连续三行，再列同样的利润行；不可先列四川所有科目再换隧道。每个比例能看到分子和分母，不仅报告百分比。图旁解释同向/反向走势，不能把共变当已证明行业因果，也不能把白酒高ROE等同于投资价值更高。
