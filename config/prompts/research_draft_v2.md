# 第一轮：完整研究初稿

这是固定三轮的第一轮。基于本轮冻结材料，确定公司如何估值的主线，判断同行及可比范围，建立证据、替代解释与反证。旧模型报告是待审底稿，不是事实权威。

输出一份自足的Markdown研究初稿，包含：公司尺度卡 → 三年或实际覆盖年份的历史面板 → 业务与价值主线 → 利润、现金、占款及资本配置 → 估值条件与反证 → 主要未决事项。必要的公司、科目、分母和年度不因压缩而省略。没有市值如实标注，仍解释账面和经营尺度。

排版示例（这里只示范格式，必须用投递材料的实际数字）：

| 公司/尺度 | FY2023 | FY2024 | FY2025 |
|---|---:|---:|---:|
| 示例公司/货币资金 | 原值 | 原值 | 原值 |
| 示例公司/受限货币资金 | 原值 | 原值 | 原值 |
| 示例公司/受限占比 | 明示分子÷分母 | 明示分子÷分母 | 明示分子÷分母 |

关键判断的写法应为“受限资金X亿元，占货币资金Y亿元的Z%，较前期如何变化，因此对哪个判断有什么影响”，而不是只列X亿元。披露值与模型算术结果明确区分。

把图表放在相应论证旁，按共通chart约定提供完整数据。至少逐一考虑增长与回报、利润到现金、占款、资本配置这些问题；没有资料则说明本次不能画什么及影响。禁止为了图数补数。每图旁写问题、读图结论与边界。下一轮会看到这些数据与实际PNG，不能声称本轮已完成看图审查。
