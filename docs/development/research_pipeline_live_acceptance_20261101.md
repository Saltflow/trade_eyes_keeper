3. Docker：复用原研究镜像，仅新增离线测试依赖层。真实错误候选退出1，修复候选退出0；非root、禁网、只读、cap-drop、PID/CPU/内存限制均实测。专用结果挂载真实可写，权威宿主回执在挂载外。

6. 用户随后明确批准复制中国海油2022—2025的4份已有提取JSON、完整对齐及摘要。7个文件逐一核验SHA，未上传PDF；完整财务研究承接前述费用后的剩余额度，原成功提取、对齐、摘要均复用。

最终状态、逐attempt费用、三轮研究原文和本地交付导航由`data/acceptance/research_pipeline_live_20261101/`保存，不能只看队列结束判断数据或财务结论正确。

## 实机暴露的缺陷及处理

| 缺陷/限制 | 证据及处理 |
|---|---|
| 原子写入后的候选为0600，非root容器读不了 | 真实Docker收集阶段PermissionError；只规范隔离公开workspace权限，原目录及凭据权限不变 |
| 原validation依赖公开config加载器/规则，候选缺件 | 先保留失败；只读加入明确公开资产，规则顶层白名单拒绝私密配置，Pi仍不能改它们 |
| Pi模型轮次与维修轮次都叫round | 新测试先红后绿；模型轮次改为model_round，run/incident/seq/at归属不能被payload覆盖 |
| 冻结目录有JSON示例，却缺维修测试源码 | 新测试先红后绿；冻结允许的维修及validation测试与公开依赖，之后live测试改变也不替换冻结证据 |
| 镜像安装依赖发生PyPI读取超时 | 改用服务器已安装依赖离线构建，记录实际版本与镜像ID；维修容器保持禁网、不pull/install |
| 模型JSON协议出现尾随DSML标签 | 严格拒绝并保留原响应，受两轮上限约束，不剪裁原文伪装通过 |
| 复核没有新chart块时丢弃初稿已有PNG | 正式流水线测试先红后绿；保留阶段限定的原图并合并新图，制图数量/问题写事件。旧已成功研究不重发，原第三轮未收到的图只作离线附录 |
| Linux默认绘图字体缺中文字形 | 实际PNG核验发现方框字；增加现有Noto/WenQuanYi字体回退，用同一原始chart数据离线重画，原图仍保留 |

运行helper自身曾有启动模板/导出参数错误，旧日志及失败记录保留；它们与正式执行代码的缺陷分列。代码版本使用code、code_r2…code_r5的新增目录，旧freeze、请求、raw及usage未改。
