# 可管理的个人触发器

2026-10-31，v1.21.0。个人触发器通过飞书自然语言管理，复用现有服务、
SQLite 执行队列和报告工作进程。全局定时日报/简报的旧筛选配置继续兼容。

## 用法

向已开放的飞书机器人发送以下独立消息即可；群聊需按机器人现有规则 @ 它。

| 消息示例 | 行为 |
| --- | --- |
| `11月2号逆回购到期` | 当前年份的 11 月 2 日 09:50 提醒，回执显示完整日期、时区及编号 |
| `11月20号逆回购到期` | 独立保存另一条提醒 |
| `任何监控标的发三季度报告的当天和次日发简报和日报` | 动态使用当前监控池；确认正式三季报后当天发送，次日 09:50 再发送，包含周末 |
| `601088跌到50以下了发简报` | 当前有效开市时段的最新价严格小于 50 时发送；日内最低价不代替最新价 |
| `拉取已经激活的触发器` | 列出自己的活跃规则及持久编号 |
| `查看全部触发器` | 同时查看暂停、结束及删除记录 |
| `remove trigger 1,2,3` | 按持久编号批量删除；不存在的编号逐项说明 |
| `暂停触发器1` / `恢复触发器1` | 管理已有规则，编号不变 |
| `修改触发器1的时间为10:00` | 修改时间并保留编号 |
| `修改触发器4的阈值为48` | 修改简单价格阈值；复杂规则使用完整条件更新 |
| `每天09:50提醒我检查逆回购` | 明确时刻的重复提醒 |

未给时刻的到期提醒默认北京时间 09:50；今年日期已过、日期不存在或条件
不完整时询问缺项。示例和说明性引用不会自动建成真实提醒。

## 条件与范围

`trigger_manage` 支持 create、update、list、get、pause、resume、remove、catalog。
身份、会话和投递地址来自认证消息，模型不能指定其他用户或收件人。
每个用户的编号单调递增、删除后不复用；列表顺序变化不会改变删除目标。
创建按消息及规范规则幂等，修改使用 revision 比较，防止覆盖并发修改。

字段目录覆盖日报公开模型字段及安全扩展字段：行情、估值、技术指标、
股息、信号、公告、组合结果等。条件可按 all/any/not 组合，支持比较、区间、
存在性和集合条件；不执行 Python、SQL 或任意代码。字段目录说明单位和数据来源。
未知字段不会假装保存成功，缺失或过期数据不会当作零或条件不成立。

最新价使用实时行情和交易所会话校验，默认新鲜度上限 120 秒。免费历史行情、
技术指标和估值按依赖获取；其他基本面、组合与研究字段使用已准备的日报/简报
安全快照，保留逐字段原数据时点。触发判定不会自动运行付费模型、搜参或回测。
尚未准备的昂贵字段等待下一份有效报告；可显式设定字段新鲜度。

报价条件通常每 30 秒检查；公告和历史指标的采集缓存最长 5 分钟。定时提醒
和已知公告次日时间使用共享执行器的精确截止时间唤醒，不等待慢行情请求。
实际发送还受服务可用性、报告排队和来源响应时间影响，不承诺秒级行情推送。

“任何监控标的”在每次采集时读取当前配置。条件标的仅用于触发原因；所发简报
和日报始终保留该次配置的完整监控池。个人动作只投递到创建动作的认证
飞书会话，不借全局邮件或 webhook 广播。手动日期动作与公告动作可在周末执行，
报告保留真实行情时点，不把旧收盘价伪装成实时价。

## 执行与恢复

条件默认在首次有效命中时触发，明确变为不成立后重新布防；连续命中和数据未知
不产生重复通知。公告按来源事件、日期偏移和动作去重；简报、日报各有独立动作。
同一轮发现多个公告时，同一触发器、会话、日期的同类报告合并发送一份，逐事件
回执保留；后续新公告仍可触发更新。修改条件会按新条件重新布防，仅改名称不重发。
一次性日期规则的全部动作结束后进入已结束状态。

命中记录、待执行动作、队列提交和 run 绑定使用同一 SQLite 事务。服务重启可
恢复待执行动作；已提交动作从持久执行回执结算。结果不明和部分发送不会自动
重发。已提交不等于已送达，列表和详情使用实际投递结果。

删除、暂停或修改会使旧 revision 失效，取消尚未提交的动作；报告启动及每次
外发之前再次检查规则、用户、会话、revision 和 run 绑定。正在投递或已送达的
内容可能无法撤回，回执会说明这一边界。未知结果保留审计记录。
