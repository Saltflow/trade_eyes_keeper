# 第二阶段模型正文：离线修补与验收（2026-10-24）

交付目录：`data/fundamental_data/stage2_model_context_20261024_125223_final/`。
模型输入是 `模型输入.md`，每家公司有单独的 `模型正文.md`；HTML仅预览同一正文。
`数据保留.json` 和 `对齐目录.json` 是离线证据，不默认送入模型。

## 边界与实现

- 第一阶段源码、schema、prompt、示例、请求、响应及旧结果全部不动；新增API调用0。
- 新入口 `scripts/build_financial_context.py` 只读取已有批次，不导入原V2提取、传输、展示或研究模块。
- 整理逻辑位于 `src/fundamental_data/model_context.py`，网络在命令入口被明确禁用。
- 表匹配同时保留原表标题、子表、模块、主题、范围与明确口径，避免宽泛的附注代码合并不同原表。
- 冻结合约已经明确的CAS/IFRS/HKFRS/US_GAAP按固定代码匹配；不同显示名在正文列出，不推测同义词。
- 列身份只来自明确的有效期间、角色、版本及调整等字段；同期间多列无法区分时保留原表，不使用行号造列。
- 行身份未定或重复时保留独立行，明确标注，不按出现顺序匹配；实际列集合不同的行分块排列，不制造空矩阵。
- 共同单位、币种和统计口径只展示一次，列/单元格例外单独注明；所有原值、百分比、区间和缺失原因继续保留。
- 政策只对正文及适用口径完全相同的版本复用。近似改写不做语义压缩，也不擅自摘要。
- 无法解析的7份旧响应按原字节另存附件；另4次失败没有正文可恢复。不修JSON、不调用模型补盲。
