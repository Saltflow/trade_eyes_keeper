# 共享资料、模型网关与通用执行库本地落地验收

2026-11-01。已完成本地源码接入；本轮没有提交、推送、部署、服务器操作或真实模型调用。新加坡、日本数据源及中国大陆服务器验收已列入[活动Backlog](todo_backlog.md)，尚未执行。

## 实际交付边界

| 层 | 实现 | 本轮接入 |
|---|---|---|
| 部署身份 | `src/shared_contracts/` | 明确绝对authority，开发/生产各自独立 |
| 通用执行/源站准入 | `src/task_runtime/` | 原core执行器为同模块兼容别名，持久lane上限、取消、超时、源站限流与阻断 |
| 资料事实源 | `src/data_hub/` | 原件URL/版本/SHA索引、中立解析、完整与预览视图、明确版本rendition、共享腾讯快照协议 |
| 模型事实源 | `src/model_gateway/` | 实际attempt、请求intent、共享容量、回执、usage、唯一生产者及unknown |
| 通用Agent | `src/agent_runtime/` | Pi/native循环；宿主注入工具、模型、桥与权限，Feishu只作适配 |
| 金融领域 | `src/research_pipeline/` | 保留单一领域实现，新增共享执行库绑定与Python门面 |

共用代码必须同时指向同一authority，才会共享同机状态。开发与生产不共享活动SQLite。跨信任用户的OS ACL、多机协调、服务器迁移不属于本轮。

领域`research.sqlite3`保留业务状态和费用投影；真实任务在`authority.execution_db`，真实模型副作用在`models_db`。不能累加投影与主账本形成重复费用。首次绑定若旧库存在活owner或未释放claim会拒绝；旧队列不迁移、不自动派发。

这些是实现迁移与治理增补，不是按上述减少行数宣称全项目净减。新增公共库共23个Python文件；金融合同、历史schema差异没有为了删行数而强行合并。

Dataset、公告、PIT、研究、V2/API接入统一原件/解析；CNINFO/HK既有布局算法作为明确版本rendition保留。三个核心原生parser方法AST对照未改变；旧values-only资料保留其缺少原件溯源的限制，不为补溯源自动下载。

普通助手的已发送请求也不再自动重发；旧retry配置可读但不触发重发。缺少费率时usage保留、费用未知，US$1单次技术额度是预留，不等于实际消费。金融研究继续守原run授权。

每个请求仍校验当前实现、已封存代码镜像、冻结输入与实际请求SHA。镜像从逐请求复制改为每执行器一次封存，减少并发启动时的fsync放大，不减少完整性核验。

## 真实资料复用及历史保护

四份中国海油2022—2025真实年报，使用既有完整prepared材料离线登记。两个独立消费者指向相同authority，取得同原件和同解析路径；网络、下载回调及原生PDF解析回调均为0。该演练是旧缓存接入与复用，不是重新解析、全文字段核验或新增研究；2024原提取缺口保留。

此前110份受保护文件全部重新验SHA不变，包括研究原文、44份PDF与已授权材料。初始950份源码/文档另有逐文件快照；本轮改动及未动文件可查`source_changes.json`，不覆盖原有脏改动。

首轮旧测试fixture曾在默认资料目录留下一个9字节`%PDF-test`对象；已按精确SHA将该对象及7份引用隔离留证，之后fixture使用临时authority。未清空共享库、未修改真实原件或源站限制；SQL测试轨迹保留审计。
