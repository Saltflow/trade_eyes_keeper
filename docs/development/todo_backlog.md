# Backlog

## P1 — 港股税后现金分红统一回测

**目标：** 按账户层保守假设，在港股除权日对持仓现金分红计提 20% 税务成本；
策略、静态基准和参考持仓必须使用同一税后总回报口径。

### 实施边界

- 在统一市场输入中传递逐日逐标的 `cash_dividend_per_share`、除权日、币种和
  `published_at`；只有 `published_at <= ex_date` 的 action 可进入历史仿真。
- 统一 Backtester 以原始可交易价格和税后现金流计算 NAV：
  `net_dividend = shares × cash_per_share × (1 - withholding_rate)`。
- 将税率配置在执行/账户合同中，默认：`hk: 0.20`、`a_share: 0.00`、`us: 0.00`；
  不硬编码，也不把该假设表述为所有投资者的法定税率。
- 搜参、日报、今日扫描、静态等权基准、外部参考标的和 `ref_portfolio`
  全部复用同一 action/NAV 路径；禁止在通知或 DCF 模块二次扣税。
- 前复权/总回报序列与显式现金流二选一，禁止重复计入分红；回测报告输出
  税前分红、税务成本、税后分红和净收益影响。

### 验收

- 100 股、每股 HKD 1.00 分红的除权日，现金净增加 HKD 80，税务成本为 HKD 20；
  未持仓、除权日前卖出和除权日后买入均不计税。
- 与拆股、停牌、最小持有期、部分卖出、外汇换算和周/季末持仓快照一致。
- 同一含分红路径下，策略、静态基准和参考持仓的 NAV 一致；改变 `hk` 税率只改变
  税后现金流，不改变信号、成交价或 DCF 公允价值。
- action 缺少可信发布日期时 fail closed，不把事后 Yahoo action 用于历史窗口。
