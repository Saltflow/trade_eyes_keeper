- 同一最终Git提交用于本地、GitHub与生产快进；全部跟踪文件逐字核对，实际运行代码

  调度、执行税率或活动策略。

  新宿主；不运行生产`--once`，不重做全量Solver、不调用模型或发送发布通知。

  临时systemd配置随后移除，不改生产`.env`及原启动命令。
