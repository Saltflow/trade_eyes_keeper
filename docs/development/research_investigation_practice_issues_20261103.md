# 投研 Agent 实践问题总表

整理日期：2026-11-03，北京时间。证据范围：2026-11-01至11-02的首轮云端验收、追加实机复验及其独立诊断。

本文汇总问题、影响、版本演进和验收边界，供审阅，不是修复方案或行业规则。此次整理只新增本文，没有修改实现、提示词、模型、配置、历史报告或验收回执，也没有运行新的付费验收。

**总体判断：Agent已能提出并计算不同业务机制，但尚不能稳定保证机制进入实际公式、公式在不同情景下保持自洽，以及自检发现自身错误。来源齐全、程序运行成功、自检通过、图表生成成功，均不足以单独证明研究质量通过。** 这是根据下述案例作出的归纳判断，具体事实与状态分别列出。

## 1. 阅读口径与状态

本文中的“最新”指本次证据范围内的最新版，不代表2026-11-03已重新运行模型或核查生产状态。

| 状态 | 含义 |
| --- | --- |
| 未解决 | 最新已核验模型或过程仍有该问题 |
| 部分改善 | 某个断点已改善，但上下游仍未闭合 |
| 候选修复已验证 | 相应候选版本有回归或实机证据，不等于生产已部署 |
| 历史问题，后续已改善 | 旧版缺陷真实存在，后版针对该项已有正向证据，不表示整案通过 |
| 待复核 | 有风险或冲突记录，但现有材料不足以确认最终处理结果 |
| 待验收 | 没有足够实际执行证据，不能当作已失败的公式或已通过的能力 |
| 不应误报 | 独立复核中已确认需要排除的错误判定方式 |

金额和股数按各案例原单位记录，不把亿元、百万元及百万美元混用。诊断中的输入变更用于检验模型，不代表现实中已发生该事件，也不自动证明修改后的输入是真实事实。

Agent自行保存、执行、读取、选版，与后来独立复制代码进行免费沙箱诊断是不同过程。独立补执行不回写原研究状态；未执行或未选版的版本仍保留原状态。

## 2. 跨案例反复出现的问题

本节是对具体案例的共性归纳，不把同一缺陷重复计数。

### G-01 研究文字识别了机制，机制未必进入计算

Salesforce说明识别了订阅、合同履约、RPO/cRPO、ARR与确认收入的区别，实际预测却不使用合同存量。把RPO与cRPO同时减半，只改变历史展示，预测和估值不动。Microsoft虽有多种驱动，也仍出现现金及股份桥错误。

影响：业务名词、来源表和模型说明看起来完整，核心结果却可能由统一增长率、利润率或转换率决定。是否出现正确名词，不能作为行业建模验收。[E2]

### G-02 来源可追踪，不代表数值含义与证据边界正确

实践中同时出现：摘要替代完整披露、本行指标用于集团、期末余额当期初、权益比例冲突未解释，以及“本次没有取得”被写成“公司未披露”。哈希、来源ID和行号只证明读的是哪份材料，不能自动证明主体、期间、单位和推导正确。[E1][E2]

影响：每个数字都能找到出处，但这些数字不一定能在同一公式中组合。

### G-03 历史桥与预测分开编写，口径和公式漂移

核电旧版历史扣增值税而预测不扣；最新版历史按共同费用分摊，预测归属却扣了另一种量。历史合计近似吻合，不能证明未来各主体的利润正确。[E1][E2]

影响：历史检查通过掩盖预测错误，模型说明所写的公式也可能与实际执行代码不一致。

### G-04 局部参数有响应，资产、负债、利润、现金和股份仍可能不闭合

银行资金成本、信用损失和普通股利润能正确变化，但资本压力下缩表只改净额与部分代理量，未同步改构成、存量和以后年度余额。Microsoft把非现金租赁新增计入现金流入，错误金额继续支持回购。[E2]

影响：只看参数变化方向，容易漏掉会持续累积的会计及状态错误。

### G-05 约束从“展示”变为“行动”后，行动仍需传到全模型

旧银行和财险资本要求变动只改变缓冲展示，不改变经营或分配。v8已出现减分红、注资、缩表和摊薄，属于改善；但银行后续资产与权益没有全部承接这些行动。[E1][E2]

影响：写有资本约束，不等于具备资本约束下的可分配利润或每股结果。约束不紧时没有响应则可能合理，不能一概要求所有输出变化。

### G-06 估值条件反向决定经营期股数，依赖关系缺少依据

Salesforce用退出FCF倍数控制未来缩股；Microsoft用DCF每股估值当未来回购价格。改变估值条件即可改变EPS，即使经营和回购金额不变。[E2]

影响：估值层、交易价格假设与融资/股数层混在一起，产生看似有利的每股结果。反馈关系本身不必然非法，但本次模型没有独立证据和明确假设支持。

### G-07 Agent自写模型、自写检查、自行解释，存在同源错误

发现的情况包括固定旧目标、自检参数不随基准变化、反解输入被当历史验证、二维敏感性比较索引错误，以及基准34项全绿但压力下恒等式失败。[E1][E2]

影响：检查数量多或全部passed，只能描述这些检查的执行结果，不能代替独立业务核验。反例也不能只选择会得到预期方向的条件。

### G-08 研究说明、计算结果、选版和完成状态容易被混为一谈

有的模型已保存但未运行，有的运行后检查失败，有的达到轮次上限但已选版，有的模型存在而研究整包校验失败。旧正式入口甚至在没有模型时继续写作。交接说明还出现“偏差小于3%”与实际约5.6%不一致。[E2][E3]

影响：不能将“有代码”“有结果”“已选定”“complete”“可用于完整估值”写成同一种成功状态。

## 3. 核电：具体问题及演进

证据：[首轮独立复核][E1]、[追加独立复核][E2]、[v8扰动与回执][E5]、[v8数值核对][E6]。

### NE-01 同一来源中权益比例冲突未被充分解释

- **发现：** v5冻结年报文本L1682–1685三门机组表列51%；L91、L12363列公司持股56%；L12420列少数股东44%。早期交接直接采用51%。
- **影响：** 项目利润归属与少数股东口径可能错误；不能任取一项或静默统一。
- **状态：** 待复核。现有复核记录不足以把这一冲突标记为彻底解决；也不能仅凭并列数字断定哪项披露错误。

### NE-02 历史扣税、预测漏扣增值税

- **发现：** v7历史桥用含税电价除以`1+VAT`，预测直接用含税收入。2025核电收入763.258亿元，相同电量及价格按13%税率复算应为675.450亿元，相差87.808亿元；2029差122.185亿元。修改VAT不影响未来结果。
- **影响：** 污染收入、利润、现金、融资与EPS，模型说明与执行公式不符。
- **状态：** 历史问题，v8该项已改善。v8把VAT由0.13改为0，历史和2025预测收入均约变为原来1.13倍，其他下游同步变化；不表示v8整案通过。

### NE-03 小数日期编码产生90月，事件传导错位

- **发现：** v8把`2025.9`、`2029.9`通过`round((date-int(date))*100)`解析为90月，影响漳州2和4。
- **独立证据：** 漳州2延后一年，预测期发电量和收入不变，却因资本金时点改变融资；将编码改为`2025.09`，2025发电量增加30.486亿kWh、收入增加10.452亿元。
- **影响：** 投产到产出、利润与建设资金的时点关系断裂。
- **状态：** 未解决。诊断只确认解析错误，不认定9月是已证实的真实投产月份。

### NE-04 项目归属从近似发展为新的预测公式错误

- **历史问题：** v6以统一少数股东比例加drift；v7以发电量加权股比乘分部利润，价格/成本不同的项目未必适用。
- **最新问题：** v8历史函数分摊共同费用，预测却用已扣费用的核电分部税前利润`sn`再按收入分配扣减。
- **数值证据：** 2025各主体用于归属的税前利润合计94.499亿元，分部税前利润174.566亿元，差80.067亿元。
- **影响：** 少数股东、归母和EPS错误；不能用分部合计近似来确认项目归属正确。
- **状态：** 未解决。更细的拆分没有自动带来更正确的模型。

### NE-05 非债务负债重复累计增长

- **发现：** v7使用`ndl *= revenue / H24.revenue`，每年再次乘相对2024年的累计增长。
- **影响：** 负债递推缺少业务依据，影响杠杆、融资与增发需求。
- **状态：** 历史问题，v8已改为按科目驱动；该局部改善不能证明融资模型完整。

### NE-06 融资、增发、注入与股份仍有未建成环节

- **历史问题：** v6增发固定为0、股份固定，无法检验资金缺口到每股结果；v7发行价变化已能传到股数和EPS。
- **最新限制：** v8基准融资采用残差债务，增发主要出现在具名条件敏感性；资产注入同时增加利润与股份的事件链仍没有充分验收证据。
- **影响：** 经营模型即使局部成立，也不能直接给出完整普通股持有人回报。
- **状态：** 部分改善，融资与注入缺口仍保留。

### NE-07 每股口径与最高买价定义曾经错误

- **发现：** v6历史2023 EPS也使用2024加权股数；`max_price_at_8pct`包含初始负参考股价，实际计算NPV，而非最高买价；估值参数还写在代码常数中。
- **影响：** 历史EPS、退出每股价值和最高买价不能混用。加权平均股数、期末股数及融资后摊薄股数需要各自明确。
- **状态：** 历史买价公式在v7已改善为未来股息与退出价值的流入现值；不能据此宣布所有年份股数口径及后续注入链已通过。

### NE-08 历史校准、隐藏常数与利息处理风险

- **发现：** v7历史股数由披露EPS反解，营运资本由披露OCF反解；新能源电量、资本化利息等还有未全部进入输入清单的代码常数。
- **另有风险：** v6净利润已扣费用化利息，OCF从净利润起算未加回，债务新增又加利息总额，存在重复计息风险。
- **影响：** 校准不能作为独立历史验证；未显式列底的输入难以敏感性分析。重复计息需要核清经营/筹资与资本化边界。
- **状态：** 校准和输入完整性仍需复核；利息项是旧版风险记录，不能未经最新复算就称v8仍确认重复计息。

### NE-09 固定旧检查目标、说明偏差及图表问题

- **发现：** v8仍把旧版675.450亿元作为固定目标，但主体价格和日期处理已改变；说明称少数股东偏差小于3%，自检实际57.92对61.37，约5.6%。
- **图表问题：** v7核电第3图把亿元和百分比放在同轴，杠杆线被压扁，虽渲染成功，可读性未通过。
- **状态：** 检查与说明问题未解决；旧核电图表问题保留，不能拿后来银行图通过替代核电图复验。

## 4. 银行：具体问题及演进

证据：[首轮独立复核][E1]、[追加独立复核][E2]、[v8扰动与回执][E7]、[v8数值核对][E8]。

本节金额单位百万元、股数单位百万股，EPS单位元。

### BK-01 归因解释和历史分解曾与数字相反

- **发现：** v5利息收入规模效应+1,939、支出规模效应+684，净贡献+1,255，却写成几乎全部来自负债端少付息；其他分部从−10,520到−8,122被写成亏损扩大。
- **进一步发现：** v6总增量1,436可对上，但规模/利率分解+3,371/−1,935不能复现披露的+1,255/+181，组件最大误差9,011.8。
- **状态：** 历史问题，v7已按披露聚合口径改进，行残差约0.4、总变化闭合，文字方向也已修正。说明“总数对”与“归因对”是不同验收项。

### BK-02 不良形成量的期初/期末、本行/集团混用

- **发现：** v7用2025年末集团贷款4,430,610作为期初；原文2024年末集团贷款4,450,480。单就时点差造成生成量相差309.972。
- **v8改善：** 已改集团期初；同时列出本行期初4,433,048，以及1.56%形成率属于本行。集团/本行条件生成量69,427.5与69,155.5，差271.9。
- **影响：** 修正期初时点没有消除主体差。本行率乘集团余额仍不是已闭合集团事实。
- **状态：** 时点已改善，主体及本行不良滚动证据缺口仍保留。

### BK-03 资本底线原来只展示，现在响应后仍不闭合

- **旧问题：** v6/v7将资本底线7.75%改为12.75%，只改变缓冲；v7到2028缓冲−3.8701个百分点，资产、利润、分红、股数均不变。
- **v8改善：** 2026分红7,483降为0，压降20%，补股本65,434，新增约5,072百万股；发行P/B从1改为0.6，新增股数约8,454百万股。
- **最新问题：** 压力路径净利息收入81,618，而利息收入减支出为102,022，差20,404；贷款减值40,980，而拨备滚动应约51,226，差10,246。
- **影响：** 只缩减净额，没有同步更新分量和存量。压力下再跑原恒等检查也失败，非舍入问题。
- **状态：** 部分改善，最新压力路径未通过。

### BK-04 增发没有进入总权益滚动

- **发现：** 上述v8压力情景总权益仅增加留存15,310，没有增加发行所得65,434；CET1和普通股权益的部分计算却已使用补资。
- **影响：** 不同权益口径失去同一底层资金来源，股数、资本与资产负债表无法共同解释。
- **状态：** 未解决。

### BK-05 缩表没有持续进入资产与资金明细

- **发现：** 每年资产/负债重新从2025基数按增长率构造；压降保留在RWA及当期贷款代理量，但不进入之后年度生息资产和资金明细。压力下2026平均生息资产仍为未压降基准7,313,827。
- **影响：** 压力措施没有成为以后年度的真实期初状态，利润与资本约束逐年分离。
- **历史相关：** v6原Normal 2028资产负债差96,925；同比增长差阈值只能诊断规模失配，不能替代闭合。
- **状态：** 未解决。

### BK-06 自检固定旧锚点，基准全绿不能覆盖压力路径

- **发现：** v8最终34项自检通过，但前述压力恒等式失败。敏感性计算虽已围绕当前形成率加减10bp，断言/说明仍固定1.6%/1.7%；资本及AT1反例也有固定锚点。
- **影响：** 外部改输入可能产生假失败，也可能留下没被测试的错误路径。
- **状态：** 未解决。历史事实校验与相对当前输入的关系检查不能混为一谈。

### BK-07 局部通过的边界

资金成本增加10bp，2026普通股利润减少1,775、EPS减少0.0406、CET1减少1,242；形成率增加20bp，贷款减值增加12,627、普通股利润减少11,971；AT1票息增加660，集团净利润不变、普通股利润减少660。这些是实测正向证据，不能因完整模型未通过就抹掉。

## 7. Microsoft：具体问题

证据：[追加独立复核][E2]、[冻结交接][E13]、[原样独立复算][E14]、[独立扰动][E15]、[数值核对][E16]。

### MX-01 非现金融资租赁新增被当作现金流入

- **发现：** 模型把投资拆成76%现金资本开支与24%融资租赁新增；现金桥扣除现金资本开支后，又把融资租赁新增作为现金流入。
- **数值证据：** Base FY2026按期初现金、CFO、现金资本开支、还本、股息及回购重算应为71,470.4，输出94,565，差23,094.6，恰等于非现金租赁新增。

- **状态：** 未解决。将新增租赁比例改0后现金恒等差降至舍入范围，只用于定位错误，不代表取消租赁就是修复方案。

### MX-02 用DCF估值直接充当所有未来回购价格

- **发现：** 模型没有独立交易价格路径，直接用每股DCF价值换算回购股数。
- **独立证据：** 仅将折现率8%改10%，收入、利润、CFO、投资、股息和回购金额均不变，FY2030摊薄股数却从5,397.3降到4,464.6，EPS由28.01升到33.86；每股估值242.59降至171.22。

- **状态：** 未解决。

### MX-03 资本开支反例揭示同一反馈，不能只检查方向

- **独立证据：** 投资强度每年增加3个百分点，FY2030净利润减少4,745、回购金额减少5,064.3，但回购股数反而增加59.8，摊薄股数减少208.8，EPS增加0.21。
- **解释：** 更低估值充当更低回购价格，引出上述结果；原自检保留方向失败。
- **状态：** 未解决。问题在现金与回购假设，不在于规定“资本开支上升，EPS必须下降”。

### MX-04 有差异化业务结构，但实际完成状态不能补写

模型自主区分商业订阅座席与价格、Azure消费型业务、传统许可及广告，并建立资本投入批次与折旧关系，这是已有正向证据。

但第一版因权益投资列表与数字相加而执行失败；第二版保存后预算停止，Agent未执行、读取或选版。后续5次免费独立Docker计算属于诊断，不能把原`selected_model=null`与`budget_stop`改称完成。

## 11. 复核时不应误报或过度推断的事项

1. **字段名不等于真实单位。** 旧核电装机字段虽叫`mw`，实际输入是万kW；按该口径的电量换算成立，不能只凭名字报十倍错误。[E1]
2. **约束未触发时，价值不变可以合理。** 财险最低资本改变但仍不约束分红，不能要求估值必须变化；需要核查中间量及是否真正触及约束。[E2]
3. **情景和敏感性不必机械排序。** 资本开支增加后EPS上升不自动构成错误；Microsoft已查到的问题是无依据的回购价格反馈与现金桥，不是排序本身。[E2]
4. **检查失败可能来自检查代码。** 财险二维表索引错误已经实证；检查绿灯也可能漏掉银行压力路径。[E1][E2]
5. **历史贴合可能只是校准。** 反解股数或营运资本可用于校准，但不能把校准项当独立验证。[E1]
6. **缺资料、来源冲突、访问受限和公司未披露不同。** 摘要没有、搜索失败或429都不足以证明完整公告无相应资料。[E2][E4]
7. **有模型不等于完成研究。** 保存、计算、检查、读取、选版、冻结完整性及财务质量各有状态；独立补执行不能改写Agent未完成的事实。[E2]
8. **候选修复不等于已部署。** v8、v9、v10分别对应提示词、冻结修复和搜索修复；旧运行版本未热改，生产状态只在封存时核对。[E4]
9. **超时不等于免费，也不等于已确认扣费。** 缺usage继续保留未知责任；账户范围余额变化不能直接归属某个研究请求。[E17]
10. **完整性失败不自动说明模型内容被改。** 核电旧包失效已定位为活动传输日志，但正式入口仍拒绝旧包；只有明确核验后，才能另做标注充分的独立诊断。[E4]

## 12. 当前可作出的结论与本文边界

已观察到的增量价值包括自主拆业务、回查原文、生成不同经营模型、实际运行并修订，以及部分量价成本、资金成本、信用损失、承保成本率和权益归属的真实传导。

阻断完整业务验收的问题仍包括：机制只存在于文字，主体/时点/税额混用，预测归属错误，压力后的存量未承接，融资及股数缺口，估值条件反向污染每股计算，代理变量填补关键证据，自检同源错误，以及真实成稿链路覆盖不足。

这些问题首先说明研究质量保证尚不稳定。现有证据不足以单独证明“换模型就能解决”“继续加提示词就能解决”“增加预算就能解决”，也不足以支持预定义行业公式库；本文不预先决定这些方案。

本文只记录实践问题和证据，不新增行业枚举、业务Schema、强制财务公式、修复代码或部署安排。服务active、配置哈希一致、无验收进程/容器及未部署等环境结论，均为2026-11-02封存时观察，不冒称2026-11-03重新核查的当前状态。
