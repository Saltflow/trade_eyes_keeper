# 日报港股与美股公告覆盖修复

旧公告入口仅按沪深代码前缀分支，五位港股可能被误送到深市或被基金前缀排除，
美股字母代码则直接跳过。监控清单、行情采集和公告采集是不同链路，
VOO/BRK.B 没有从清单删除。

## 实现

- 五位代码先进入披露易，内地基金前缀排除仅作用于六位代码；
  繁体/英文标题及分类使用普通、分红双窗口和每股 5/3 条选择规则。
  查官方证券内部 ID，核验返回股份代码和 HTTPS 官方链接；
  总数超过首屏时拆分日期，最多 64 次搜索，异常不作为成功空结果。
- 字母代码进入 SEC。BRK.B 映射到 BRK-B，普通公司用官方 CIK 和 submissions，
  日期交叠的历史文件有界补读；ETF 用官方基金 class ID 查询，
  避免同一信托下其他基金混入。表单类型参与重要性选择，保留原始官方文档链接。
- 港股和美股不走缺少币种字段的 A 股 LLM 金额提取，已有分红事件源保持独立。
  沪深公告源和共享权益分派关键词保留。日报各渠道消费原有 announcements 数据。
