## 最终设计及实现位置

- `src/personal_monitor/store.py`：独立 SQLite 账户、持仓、截图版本、问题行、规则层级、提醒与 outbox。认证 sender 是 owner，模型不能传入别人的 owner。账户与参考组合分别存储。
- `src/personal_monitor/engine.py`：按账户/证券/规则/层级求值和持久去重；原始比例比较，合并命中分别记账；原子领取、发送边界、失败退避、未知结果人工重发。未发送旧信号因事实或观测变化失效；已发、已提交及未知投递不隐式重置。
- `src/personal_monitor_runtime.py`：独立到期轮询及正常市场检查时点；日报开关不门控个人提醒。真实 QQ 报价、QQ/Yahoo 原始历史价格、交易日历及美股时区；闭市报价有效期止于下一开盘。明确绑定版本与场景的现金流隐含年化回报计算，不使用股息率替代。
- `src/interactive/feishu_handler.py`、`feishu_app.py`：image/post 接入、原消息时间、会话权限、认证资源下载及实际发送分类。下载固定平台资源，不接受任意图片 URL。分类保留平台消息 ID，发送结果不明不自动重试。
- `src/interactive/assistant/client.py`、`position_images.py`：专用结构化识图、明确单位换算、数量×价格≈市值、真实来源/币种/时点核对。联网核对在后端工具执行；视觉请求本身没有伪装成自动联网。
- `src/interactive/assistant/personal_tools.py`、`service.py`：模型决定语义、账户和任务选择；程序校验权限和版本。截图待补充批次跨消息/重启保存。个人操作直接执行并返回真实状态生成的回执，日期不再由模型二次计算。个人消息不隐式触发基本面补数。
- `manual_positions.py`：所有手工入口均核对用户实际写出的证券、数量及可选价格/币种；证券代码中的数字不能当数量，否定或条件清仓不能当零仓。未明确更改的行保持原事实，模型补出的字段不会直接入库。
- `immediate_reminders.py`：过去时间提醒的暂存、实际提交、实际回执及崩溃恢复。取消/改期过滤旧版本；其他会话走真实目标 outbox。长回复每条提醒在自己的平台消息发送前才提交，不能提前把后续消息标成已发送。

## 行为约定

1. 指标、阈值、比较符、范围、文案可配置；默认所有实际持仓减去继续持有例外。观察池不等于持仓，池外持仓也获取数据。无有效计算输入显示未就绪。
2. 示例 5.5%/5% 没有写入生产业务逻辑。现有数据提供器支持 expected_return 与 price；其他未提供指标不伪造数值。回报绑定 `equity_cashflow_dcf_v1`、版本、场景、币种及明确给出的假设；新研究不会自动切换。
3. 初次启用已满足的阈值会通知。重启、刷新、反复越线、清仓再买、暂停恢复、修改配置和研究均不清除已提醒层级。修改既有阈值沿用 tier ID；明确重置才重新启用。
4. 正常截图自动导入；问题行保留旧事实并暂停依赖该行的规则，其他明确行继续处理。老整图不能新增已消失的历史持仓，慢 OCR 不能覆盖手工修改。缺行不清仓；明确零持仓才清仓。手工输入可以完成纠正，不要求重拍。
5. 截图只更新个人事实，不生成交易、手续费、现金变化或参考组合变动。对历史图片核对对应历史原始价格；缺乏盘中历史证据时如实拒绝，不用当前报价替代。
6. 条件检查沿用 scheduler 的现有检查时点。默认交易中报价最多15分钟，期限可配置；闭市只接受核验的最新完整交易日。条件来自同一个实体，不能把不同证券的名称和指标拼成命中。
7. 到期任务来自明确聊天/截图指令。N 天后由服务端按原消息北京时间计算 N 个自然日、同一时刻。仅日期默认09:50，可传配置覆盖。到期独立于报告、行情、周末和持仓；停机恢复补一次，不声称资金已确认到账。
8. 明确创建过去时间且目标为当前会话时，当前回复就是提醒。目标为其他已验证会话时，本会话返回管理回执，提醒排队发到真正目标。即时回执也有持久投递状态：成功完成，明确失败退避补送，未知/崩溃待核查。不会把未送达的回复当已成功。
9. 模型决定投递位置、改期/取消对象及重复表达/另建，执行后回告结果。目标 route 必须是该用户实际到达过且仍允许的会话。真正缺信息才补问。取消已提交平台的消息不能承诺撤回。
10. 同平台消息去重独立于短期对话保留期；截图内容去重与任务业务状态另行保存。发送成功、明确失败、结果未知分别记录。未知状态可显式要求重发，并回告可能重复。

## 验收证据边界

“自动通过”指固定输入、时钟和故障注入下，真实实现的状态/通知数量符合预期；外部网络边界按测试说明受控。它不等于真实飞书收发或真实券商截图识别准确率通过。

| 项 | 内容 | 验收与证据 |
|---|---|---|
| A01 | 可配置指标、阈值、文案 | 自动回放；真实模型自然语言配置6%/4%规则，受控价格依次触发两层，重复不再触发 |
| A02 | 实际持仓、池外持仓、例外 | 自动回放；个人存储不依赖全局股票池 |

## 运行与复核

所有 pytest 必须使用 workspace 内的 `--basetemp`（默认系统临时目录在本机沙盒会 WinError 5）。

```powershell
python -X utf8 -m pytest -o addopts= tests/personal_monitor tests/test_personal_monitor_runtime.py tests/interactive/test_personal_images.py tests/interactive/test_feishu_app.py tests/interactive/test_assistant_routing.py tests/notification/test_report_triggers.py tests/validation/ -q --basetemp=data/pytest_personal_focused_stable
python -X utf8 -m pytest -o addopts= tests/interactive/ tests/validation/ tests/test_schedule_manager.py tests/notification/test_report_triggers.py -q --basetemp=data/pytest_personal_regression
python -X utf8 scripts/accept_personal_monitor.py
```

以下命令会真实调用配置的模型或公开行情，使用隔离测试 DB，不启动 Bot、不向飞书发送：

```powershell
python -X utf8 scripts/accept_personal_monitor.py --live-model --live-market
python -X utf8 scripts/accept_personal_monitor.py --live-rule-model
python -X utf8 scripts/accept_personal_monitor.py --live-screenshot-flow
```

证据目录：`data/acceptance/personal_monitor_20261021/`。包括 JUnit XML、真实模型原文/操作结果、公开行情时点/来源、合成图、隔离 SQLite、范围校验、以及后续生成的本次增量补丁。合成图明确标注 SYNTHETIC，不能作为真实持仓证明。

完整真实验收仍需要：人工标注的脱敏真实持仓/回购截图集，以及隔离飞书测试应用和会话。在这些资源下验证实际入站附件、实际可见通知和重启重投去重，再关闭 A09/A10/A20。
