# 契约4.0离线验收与单次试验

本目录为新版本独立证据，旧结果没有覆盖。`offline_report.json`记录41个规范块、31个真实历史响应和旧三年数据保留对照；`pytest_result.json`记录冻结前的最终回归。

离线已确认：28个可解析历史对象的256表、2675行、8675格原字段保留；其余3份非法JSON保留原文，不猜测补括号。旧三年234张输入表、8149个numeric单元格和105项政策保留。旧3.0不伪造4.0身份，不将独立保留宣传为已跨年对齐。

运行期不调用业务validator；独立`audit`只生成报告。严格JSON不丢键、预算、冻结和防覆盖保护仍在。局部结构或口径不足只影响局部整合，不删除已有数据。规范反例覆盖稳定身份、原名差异、单位/币种、时点与期间override、显式null、重复行、合计抵销、部分日期精度和未知比较基期。

新付费试验限定同一招行2023完整362页年报的notes_operations块，128K输出、thinking enabled、最多一次、零自动补调，峰时未缓存规划自限US$0.50。调用前冻结完整代码、prompt、请求及验收基准。

试验目录：`data/fundamental_data/cmb_2023_operations_contract4_20261024`。`experiment_plan.json`为调用前核对，`response.body`/`content.txt`/`parsed.json`为逐步原始记录，`阅读.html`为原对象展示，`summary.json`记录用量和冻结核对，`offline_acceptance.json`记录调用后独立只读验收。

178个已核对源表单元格来自原PDF物理260—261页。自动对照按分部/年度/有效时点期间及值的出现次数比较；科目语义仍需结合原文检查，这不是通用财务正确性验收器。一个经营块的通过不代表31行业或完整三年已通过真实模型验收。若关键验收失败，不再付费试错或修改冻结版本，应保留失败证据另起设计。
