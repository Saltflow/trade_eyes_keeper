## 实现

- 元数据与实际可写规则共用同一注册表；天数1–3650、成功提取计数0–1000、PDF体积
  0.1–100 MiB，严格拒绝bool冒充数字、NaN/Inf、错误类型及越界输入。
- 缺失旧值保留None并附old_configured/default；设置成代码默认值也会显式保存。
  原配置畸形值不返回模型/预览，父级结构异常拒绝修改；合法但超新范围的旧数值可修。
- 复用ConfigStore锁、预览版本检查、按文件分组和原子写入；用户明确确认后保存。
  下次任务读取，不声称立即改变正在执行的任务。
- 模型修改前重新查询字段能力，不沿用旧历史或文档的只读结论。未给新值不自行创建
  任意参数提案；已开放字段无需主机编辑。
- 准确描述LLM计数按单次公告丰富调用累计成功提取数，并非全报告请求总额。
