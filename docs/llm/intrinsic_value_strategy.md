# 股权现金流 DCF 与下一季报价格区间实验

## 目标与边界

本模块是离线研究，不接入当前活动技术策略、搜参、日报或参考持仓。它输出两类
结果：

1. 逐时点内在价值：低、中、高三个估值场景。
2. 从当前估值日有效至下一份新财报披露前的价格下界与上界。

历史估值只能读取评价日已经披露的数据；历史价格路径只用于形成标签，永远不能
进入当时的估值。历史主观风险必须具有 effective_from，没有生效日期的当前观点
不会倒灌历史。

## 市场股权成本、个人必要回报率与现金流口径

现金流、盈利能力、DDM和残余收益专家全部使用股权现金流口径。CAPM只用于解释
市场如何给风险定价：

    market_cost_of_equity = risk_free_rate + beta × forward_ERP

实际估值使用明确的个人必要股权回报率，默认三档为：

    downside = 8.0%
    base = 7.5%
    upside = 7.0%
    terminal_growth = 2.0%

逐场景实际贴现率为 max(个人必要回报率, 市场CAPM股权成本)。这意味着低Beta
不会把美的这类公司的估值贴现率压到4%附近；但如果市场CAPM明显高于8%，高风险
公司的贴现率仍会被抬高。个人必要回报率表达资金规模、承受损失能力和机会成本，
不是把CAPM重新包装成“精确WACC”。

现金流 DCF 当前使用 TTM经营现金流 - TTM资本开支 的每股值。由于数据中还没有
逐时点净借款，它只是显式的 FCFE 代理，而不是严格 FCFE；因此不做净债务桥，也
不声称它是 FCFF。资本结构和 WACC 可作为诊断展示，但不参与本版估值。不得把
股权现金流用 WACC 贴现，也不得把企业现金流用股权成本贴现。

Beta 使用估值日前可得的2/3/5年日频和周频价格估计；市场CAPM的低、中、高场景
来自逐时点资本市场输入和Beta不确定性。缺失同期输入时会明确标记为配置回退，
不会把今天的资本成本倒灌历史。

## 反向DCF

反向DCF先用当前价格、个人必要回报率和2%永续增长，求市场隐含的五年显式增长；
再与财务历史推导的基本面增长并排比较。它用于回答“市场正在为多少增长付费”，
不用于把现价隐含增长反向写回公允价值。以下合同必须始终成立：

- 改变现价会改变市场隐含增长；
- 改变现价不会改变低/中/高内在价值或保守买入价；
- 市场CAPM与实际必要回报率在JSON和HTML中分别披露；
- 主观风险只改变保守买入价和下一季报前价格区间，不改变现金流或贴现率。

## 主观风险

主观风险与贴现率分离。配置示例为：

    instruments:
      "000958":
        price_haircut: 0.05
        adverse_event_probability: 0.25
        adverse_event_loss: 0.40
        uncertainty_multiplier: 1.0
        reason: "重组预期、治理和资产注入质量仍不确定"
        effective_from: "2026-08-20"
        expires_at: "2027-03-31"

- price_haircut：确定性的额外价格折价。
- adverse_event_probability × adverse_event_loss：事件的期望损失，用来下移
  区间中枢。
- adverse_event_loss × sqrt(p × (1-p)) × uncertainty_multiplier：事件损失的
  不确定性，只扩张区间下界。
- reason、effective_from和expires_at使人工判断可审计、可到期。
- extra_discount_rate被禁止，避免在股权成本与价格折价中重复计价。

这些数字必须由人在当时显式填写，不能从未来价格拟合，也不能用事后事件补录成
历史已知风险。

## 下一季报价格区间

每个历史样本是一段完整的“报告披露日到下一份新报告披露日前”的前复权等价价格
路径。区间中枢在当时现价和DCF公允价值之间作对数混合；半宽由基础波动宽度、
绝对Beta和DCF场景不确定性组成。主观风险再调整中枢和下界。

优化目标为：

    mean_coverage
    - width_penalty × relative_width / max(abs(beta), beta_floor)
    - shortfall_penalty × max(target_coverage - mean_coverage, 0)^2

用户草式中的价差项必须是负号；正号会奖励无限宽区间，与“覆盖率高且价差低”
相矛盾。这里的 mean_coverage 是下一次披露前每日价格位于区间内的平均比例；
报告另列更严格的“整段路径全部位于区间内”比例。

参数只在时间较早的校准段选择，最近30%的报告日期完全留出。部署参数可以在完成
留出评价后用全部已完成历史重估，但留出指标保持冻结。

## 强制基线

强制基线与DCF模型使用相同的时间切分、Beta、搜索网格、覆盖率和宽度惩罚，但：

- 区间中枢固定为当时现价；
- 不读取公允价值；
- 不读取DCF场景宽度；
- 只允许基础宽度和Beta宽度。

因此只有时间留出目标分高于该基线，才能说明DCF为“下一季报前价格范围”增加了
信息。即使通过，当前也不会自动进入生产。

## 仍保留的一至两年诊断

旧的252/504交易日横截面Rank IC仍保留作长期价值诊断，但不再是本版价格区间的
主目标。86家公司首轮结果显示，安全边际Rank IC和首尾组收益差弱于简单账面收益
率，不能据此宣称价值模型有效。

最新区间实验的完整参数、留出指标、逐段标签和当前上下界分别写入：

- report.json
- next_report_validation_rows.csv
- next_report_latest_forecasts.csv
- report.html
## 86家公司下一季报区间结果（2026-08-20）

真实数据合同：

- 86家公司，1,574段已完成的报告到报告价格路径。
- 1,132段用于校准；最近442段从2024-08-27起完全留出。
- 真实510300本地价格缓存用于逐时点Beta；1,224/1,574段取得真实估计，
  其余早期样本显式回退为1。Beta中位数0.9506，范围-0.0369至1.5348。
- 510300缓存是未复权ETF收盘价，现金分红未进入Beta基准收益，报告保留该限制。

宽度惩罚从0.25到1.50的留出前沿为：

| 宽度惩罚 | 平均日覆盖率 | 平均相对宽度 | 整段完全覆盖率 |
| ---: | ---: | ---: | ---: |
| 0.25 | 93.98% | 56.78% | 74.89% |
| 0.35 | 91.99% | 48.78% | 66.97% |
| 0.50 | 91.10% | 46.03% | 63.57% |
| 0.75 | 87.26% | 38.03% | 50.45% |
| 1.00 | 84.51% | 34.03% | 43.44% |
| 1.50 | 81.22% | 30.03% | 38.24% |

0.75之后，每缩窄4个百分点区间要损失约2.75至3.29个百分点日覆盖率，边际
代价明显变陡。因此默认选择0.75：校准段覆盖率86.12%、宽度36.91%；时间留出
覆盖率87.26%、宽度38.03%，合并日覆盖率85.55%。

关键负结论：该平衡点选择的 valuation_weight 和
value_uncertainty_weight 都为0，结果与“现价+Beta”强制基线完全相同，
DCF增量目标分为0。DCF没有为下一季报前价格范围提供可验证信息，因此
dcf_beats_beta_only_baseline 为 false，production_ready 仍为 false。

当前无人工风险覆盖时的示例区间：

| 代码 | 现价 | 预估最低 | 预估最高 | Beta |
| --- | ---: | ---: | ---: | ---: |
| 000001 | 11.05 | 9.38 | 12.72 | 0.590 |
| 000333 | 83.58 | 72.82 | 94.34 | 0.406 |
| 000625 | 7.13 | 5.82 | 8.44 | 0.861 |
| 000983 | 6.81 | 5.69 | 7.93 | 0.701 |

这些上下界是经验价格区间，不是内在价值。上述000333的293.34元结果来自已经
废弃的“直接使用4.44%低Beta CAPM贴现”口径，仅保留为缺陷证据，不能作为当前
估值。当前权威口径使用7%/7.5%/8%个人必要回报率、2%永续增长，并单独披露
4.44%市场CAPM和反向DCF隐含增长。重新运行结果追加在后续验收记录中。

## 个人必要回报率重跑结果（2026-08-21）

同一86家公司、1,574段报告到报告路径重新运行后，83家公司能形成估值。美的
（000333）的关键估值桥为：

| 项目 | 结果 |
| --- | ---: |
| 当前价格 | 83.58元 |
| 每股FCFE代理 | 5.5553元 |
| 市场CAPM股权成本 | 4.4368% |
| 个人必要回报率（下行/基准/上行） | 8.0% / 7.5% / 7.0% |
| 永续增长 | 2.0% |
| 基本面显式增长 | 10.9575% |
| 现价反向DCF隐含显式增长 | -2.6490% |
| 低/中/高现金流DCF | 67.10 / 151.27 / 210.01元 |
| 混合公允价值低/中/高 | 67.10 / 151.27 / 151.27元 |
| 含模型与主观折价的保守买入价 | 48.01元 |

293.34元的旧中枢已被消除，但151.27元仍高度依赖历史推导的10.96%显式增长。
反向DCF表明市场实际上在为约-2.65%增长定价；这不是自动把增长改成负数的理由，
而是要求后续补充前瞻订单、利润率、资本开支周期和现金转换的证据，决定应将
10.96%向何处收缩。

下一季报前区间仍为72.82–94.34元。时间留出的平均日覆盖率87.26%、平均相对
宽度38.03%、目标分0.50345；DCF候选的 valuation_weight 和
value_uncertainty_weight 仍均为0，与“现价+Beta”强制基线相同，增量目标分为0。
因此本轮修复解决了贴现率语义和估值量级错误，但没有证明DCF能够预测短期价格
路径，也不得据此接入生产。
