# 指数参考公司池逐时点回填合同

本链路为基本面表征研究准备数据，不改变活动策略、优化产物或日报。

## 当前公司池

- 当前成分来自中证指数官方文件：沪深300（`000300`）、中证500
  （`000905`）和上证红利（`000015`，对应 `510880`）。
- `index_constituents_20260818.json` 合并后包含807家公司；成分日期为
  2026-08-18，权重日期为2026-07-31。
- 成分身份只表示清单日期当天的研究公司池，不允许把今天的指数成分身份回填为
  历史事实。历史模型只可读取各公司当时已经披露的财务快照。

## 批处理入口

```bash
python scripts/backfill_reference_universe.py \
  --manifest data/reference_universe/index_constituents_20260818.json \
  --output-dir data/reference_universe/point_in_time_20260818 \
  --workers 2 \
  --evaluation-date 2026-08-18
```

- 默认使用2个独立worker进程，最多允许4个；父进程维持最多
  `workers * 2` 个在途任务，避免无界排队和网络突发。
- 每家公司完成后原子写入独立检查点。相同清单、窗口和采集配置再次运行时，
  成功项直接跳过，失败项默认重试。
- `progress.json` 可供长任务监控；最终 `report.json` 和
  `latest_reference_backfill.json` 输出市场数据、财务成功率、逐字段填充率及失败代码。
- 清单哈希、评价日期和影响采集语义的配置共同构成批次指纹。合同变化不会误用旧检查点。
- 行情、报表和解析缓存均位于显式 `--output-dir`，不会写入活动策略的数据目录。

## 数据边界

- 只使用免费真实数据和官方披露，不使用付费源、mock或默认值。
- 原始价格、前复权价格、除权因子、公司行动、报告期和真实披露日沿用
  `point_in_time_data.md` 的唯一合同。
- 本批次是公司画像训练样本，不代表指数的历史成分，也不能直接进入现有技术面搜参。
