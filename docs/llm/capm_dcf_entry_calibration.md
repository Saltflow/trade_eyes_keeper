# CAPM 股权 DCF 买入价校准合同

本文件定义独立于生产策略的历史校准工具
`scripts/calibrate_capm_dcf_entry.py`。它只生成审计报告，绝不修改活动策略、
持仓或优化产物。

## 估值输入

- 贴现率只使用点时 CAPM 股权成本：`r_e = r_f + beta × ERP`。不计算债务成本，
  也不把资本结构项伪装成 WACC。
- `r_f` 是估值日（或此前最近可用交易日）的官方中债十年国债收益率；缺失即跳过，
  不用当前利率回填历史。
- Beta 由截至估值日的 2/3/5 年、日频/周频市场数据稳健估计；不能使用未来价格。
- 永续增长率固定为 2%。显式五年增长由已披露年报的营收 CAGR、归母利润 CAGR、
  FCF CAGR、`ROE × CAPEX/OCF` 再投资代理和 ROE 趋势加权、裁剪得到。
- 估值先按估值日已披露的官方行业分类与已披露现金流历史路由，路由本身不读取未来
  价格，也不参与参数排序：

  | 路由 | 估值链 | 禁止事项 |
  | --- | --- | --- |
  | 金融业（行业代码 `J*`） | 残余收益：每股净资产、归一 ROE、派息率，ROE 向 CAPM 股权成本收敛 | 禁止把经营现金流减 CAPEX 当作 FCFE |
  | 周期行业或现金流峰值/高波动公司 | 最近最多七个可复核年度的 FCFE 中位数；显式期不使用 FCF CAGR | 禁止用单年景气峰值同时抬高现金流和增长 |
  | 其他公司 | 最近至多三个可复核正 FCFE 代理的中位数 | 不得绕过披露日与一致性筛查 |

  FCFE 代理定义为经营现金流减资本开支。每个年度必须同时有正收入和正归母利润，且
  FCF/利润与 FCF/收入位于配置的合理区间。这不是对异常值做截断；异常年报记录被拒绝。
- 所有历史股本先通过当时已经披露的拆股、送配等公司行动滚动到估值日口径，再计算
  每股现金流；原始价格也在同一股本口径下比较。

令财务增长为 `g_fin`。主观风险溢价按用户约定的 ERP 分段实现为保守增长：

```
g_used = g_fin / 1.25,  ERP > 5%
g_used = g_fin / 1.50,  ERP <= 5%
```

直接把 `g_fin` 乘以 1.25 或 1.50 会提高 DCF 公允价值，方向与“风险溢价”相反；
因此该乘数作为增长折减使用，并在每条结果中审计输出。

```
fair_value = Σ[t=1..5] FCFE0 × (1+g_used)^t / (1+r_e)^t
           + FCFE5 × (1+2%) / (r_e-2%) / (1+r_e)^5
buy_price  = entry_fraction × fair_value
```

金融路由则使用：

```
fair_value = B0 + Σ[t=1..5] (ROE_t - r_e) × B_(t-1) / (1+r_e)^t
           + terminal_residual_income / (1+r_e)^5
```

其中账面净资产按 `ROE × (1 - payout)` 前滚，ROE 按配置速度向 `r_e` 收敛；负的
终值残余收益不会被静默删除。

只有 `r_e > 2% + minimum_discount_spread` 时才允许计算终值。

反向 DCF（用当前价格反解隐含增长）只可作为报告诊断，用于发现市场与财务假设的分歧；
它不得回流到上述 `g_fin`、参数选择或历史标签，否则会把价格噪声伪装成基本面预测。

## 历史校准与接受门槛

- 每个公司/报告日只读取 `published_at <= evaluation_date` 的快照。
- 买入限价必须在随后的 252 个有效交易日内被原始日低价触发；未来的拆股只用于
  统一每股口径，未来股息不改写可成交价格。
- 买入价还必须低于估值日市场价的配置比例（默认 `95%`）；否则它不被视为“立即以
  市价成交”的伪命中，仍在样本分母中保留。
- 触发后再观察 252 个有效交易日；若至少 50% 的收盘价高于买入限价，记为成功。
- 时间上较早的报告日用于网格选择，最后的连续日期后缀完全留出。留出价格绝不参与
  训练、参数排序或增长/Beta 计算。
- 每个 ERP 情景都必须同时满足：最小成交笔数、最小一年内触发率、至少 70% 的进入后
  成功率以及 Wilson 95% 下限。任何一个情景无成交、无后验观察或失败，候选都不可用于
  生产；缺失情景不能被排序器忽略。
- 触发率和最小笔数是“该估值链在当前研究池是否有足够历史证据”的校准门槛，默认不是
  对全市场要求 20% 的买入频率。每条链还必须有足够的训练期样本；未达到该项门槛的链
  显式标记为未支持、只能不产生信号，绝不借用另一条链的参数。
- 参数按三条估值链分别在训练期选择，再将已支持的链交由同一整体 Gate 复核。这样金融
  残余收益的安全边际不会被周期 FCFE 的极端现金流覆盖；单一模型缺乏证据时保持离线候选
  状态。
- 若当前配置标的池本身没有任何链达到历史证据门槛，校准器必须写出拒绝报告（所有链
  为“不支持”），而不是回退到广义研究池参数、抛出无法审计的异常，或继续生成策略信号。

该门槛防止用几乎不会成交的极低价格，或用异常现金流生成的高价格，伪造高胜率。
通过该门槛只表示“可进入手动统一策略实验”，不等于自动生产激活；最终仍须由当前
配置标的池的因果面板和统一收益/回撤/基准 Gate 验收。

### 校准标签与运行时委托的边界

上面的 95% 条件是历史标签的**限价触发定义**，不是未来 `capm_dcf_value` 策略的
运行时买入过滤器。若把它复用到策略，就会出现“DCF 买入价高于现价反而拒绝”的方向性
错误。冻结政策的运行时合同是：

```text
P <= entry_price               -> 新快照当日立即产生一次买入事件
P > entry_price 后首次向下穿越 -> 产生一次买入事件
P >= fair_value                -> 产生卖出决策
```

策略只消费已经冻结的路由/增长/基础安全边际；它不会在接收标的池上利用这些未来价格
标签重新选参。公司成本仍是 `r_f + beta_i × ERP`；接收池平均 Beta 只允许改变
安全边际，不得改写公司 Beta 或 CAPM 贴现率。由于 DCF 估值是未复权的每股口径而
共享回测以 qfq 价格估值，运行时必须将同日公允价与买入价乘以同一 `qfq_factor`，保持
原始价格不等式等价；没有该因子或快照过期时必须不交易。

## 冻结政策向小标的池应用

大盘研究池的训练事件数用于选择并认证估值政策；它不能被错误地当作配置内小标的池
的最低样本量。已通过留出的政策可使用下列命令在小池上做纯应用回测：

```powershell
python scripts/calibrate_capm_dcf_entry.py ... `
  --frozen-policy-report data/analysis/<broad-run>/report.json `
  --symbols <configured-a-share-codes> `
  --output-dir data/analysis/<application-run>
```

该模式要求源报告的经济合同和配置哈希匹配，且源报告自己已通过留出。它只评价源报告
`validation_start` 之后的接收池事件，不会重新搜索参数、按接收池样本量拒绝政策，
也不会使用接收期标签回写政策。接收池的小样本结果只是时间外迁移证据，仍不能替代
统一回测的收益、回撤和基准 Gate。

## 可复现运行

```powershell
python scripts/calibrate_capm_dcf_entry.py `
  --data-root data/reference_universe/point_in_time_20260818/.../dataset `
  --benchmark-prices cache/data/510300.csv `
  --industry-history data/reference_universe/industry_classification_history_official_2020q4_2025h2.json `
  --risk-free-rates-json data/analysis/.../risk_free_rates.json `
  --output-dir data/analysis/capm_dcf_entry_calibration_<run>
```

报告同时保存合同、完整参数网格、训练/留出指标、逐条价格标签、CAPM 输入和无风险利率
来源。没有通过门槛时，正确产物是明确的拒绝报告，不是静默选择“最不差”的参数。
