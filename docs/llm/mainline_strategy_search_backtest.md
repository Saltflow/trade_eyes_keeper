# 当前主链路：报告、显式回测与历史产物

截至 2026-11-04，策略搜索与优化整套功能已从源码删除：Solver、自动搜索窗口编排、Gate、候选评价/晋升/激活、优化进程/锁/恢复、通知，以及相关 CLI/Bot/配置入口均退出当前支持范围。本文替代原先的当前搜参说明；带日期的历史验收记录保留当时含义。

## 报告与 Ke 展示

受管触发器和显式日报/简报入口派发既有完整报告 worker。报告统一展示行情、基本面、分类事件和合格 Ke 曲线。Ke 曲线由独立的历史仿真产物提供，校验策略身份、日期、覆盖及新鲜度，不回退到旧技术回测或优化结果。

受管动作只有 `daily`、`brief` 可执行；`optimize` 保留类型兼容且拒绝执行。固定日报、启动日报、固定简报能力保留，线上是否启用以目标配置与实际注册记录为准。

## 显式手动回测

`/backtest 代码 起 止` 保留，通过既有策略合同构建 `TradePlan`，交给唯一 `Backtester` 成交、记账和评价。参数由显式配置或已有只读绑定提供，不调用搜索器，不生成候选，不切换活动指针。

执行继续区分 qfq 指标数据和 raw OHLC 成交数据；现金分红、税、拆股及实物分派按现有因果来源处理。成交日期、整手、手续费、持有期与基准不因优化器下线而改写。缺少必要执行数据时明确失败，不生成零资产伪结果。

`config/optimizer_constraints.yaml` 和对应配置 loader 保留历史命名，仅保存共享执行、WF、基准与回测 profiles。`src/search/workflow.py` 仅为两个既有 PB 脚本保留显式手动 WF 评价辅助函数，无自动搜参、Gate 或产物发布；历史 solver/gate 元数据不执行。

## 参考持仓和历史数据

参考账户保留估值、公司行为记账、手动买卖/重置，以及既有持仓和交易历史。历史搜索运行与执行快照留存为只读资料；不再重新搜索、晋升、激活或自动调仓。机器人经现有数据工具发现和读取已保存产物，不能将历史报告误称为当前运行结果。

## 独立研究边界

年报提取、跨年整合、调查建模、财报研究和 Pi 会话继续沿用各自链路。研究估值、数据采集、期权资料与仍有消费者的数学计算不等于被删除的参数搜索功能。
