# 667 标的反向 DCF 共识分类

报告：`data/analysis/reverse_dcf_consensus_667_20260822/`。

截至 2026-08-18，使用逐标的历史 beta 和 CAPM 股权成本，对四个估值专家逐一求解市场隐含的五年显式增长率。剩余收益专家没有股权现金流代理，不进入反向 DCF 候选；没有正现金流代理的标的不填默认值。反向求解边界为 `-50%~100%`，只是诊断边界，不改变内在价值预测。

| 状态 | 数量 |
| --- | ---: |
| 至少两个专家达成共识 | 495 |
| 只有一个专家可解 | 82 |
| 无可解专家 | 90 |
| 可解总数 | 577 |

旧的“只取主专家”口径只有 251 个可解标的；新的多专家候选集合增加到 577 个，增加 326 个（129.9%）。共识隐含增长分类为：隐含衰退 137、0–5% 37、5–10% 30、10–20% 69、20–30% 74、30% 以上 230。282 个可解标的的专家离散度超过 5 个百分点，应显示为高分歧画像。

这不是把 577 个结果都当成同等可靠：495 个有至少两个专家交叉验证，82 个是单专家；90 个无解必须保持缺失状态。该产物仍是研究/画像层，不自动进入搜参、日报或活动策略。下一步若作为量化特征，必须使用同一多专家合同在历史逐时点面板上 OOS 验证，并带上 `expert_count`、`dispersion` 和 `status` 掩码。
