# 潜在同行 MOE 实验契约

## 目标

本实验不预先提供行业、同行标签或公司代码。模型需要从逐时点可得的经营、
财务和市场数据中学习公司条件化的软分群，并同时完成两项相互隔离的任务：

- 定价头只读取经营画像，解释当期横截面的盈利收益率、账面收益率、
  自由现金流收益率和股息率。
- 收益头读取经营画像、当期估值和缺失掩码，预测未来 63 个交易日的
  横截面超额收益排序。

同行是门控权重相近的事后结果，不是输入。任何人工行业标签只允许用于
结果审计，不得参与训练。

## 防前视与强制基线

- 每个季度只使用发布日期不晚于评价时点的数据。
- 定价目标不得作为定价头输入，防止模型直接复制 PE、PB 等目标。
- 每个评价季度重新训练，测试季度严格位于训练截止日之后。
- 定价头必须与单一 Ridge 比较；收益头必须与单一 Ridge、均匀专家、
  全局门控以及冻结报告中的 Kalman、EWMA、Ridge 和旧 MOE 比较。
- 软同行只有在跨随机种子稳定后才有解释资格。

## 2026-08-19 局部 86 家公司实验

修复定价目标自抄问题后的有效结果：

| 指标 | 潜在同行 MOE | 强制基线 | 差值 |
| --- | ---: | ---: | ---: |
| 定价横截面平均 Rank IC | 0.4887 | 单一 Ridge 0.4545 | +0.0341 |
| 未来收益平均 Rank IC | 0.0317 | 内部单一 Ridge 0.0349 | -0.0032 |
| 未来收益平均 Rank IC | 0.0317 | 冻结 Kalman 0.0522 | -0.0204 |
| 收益首尾组差 | -0.18% | 必须为正才有投资意义 | 未通过 |

四个专家没有塌缩，最小平均负载约 21%，门控也随公司变化。但五个随机种子
之间主专家一致率仅约 35% 至 48%，Top-5 软同行的中位 Jaccard 只有 0.111。
因此当前模型只能说明“混合非线性定价函数略优于单一线性函数”，不能说明
已经发现了可靠同行，更不能作为收益策略输入。

专家数量从 2 增至 5 时，定价 IC 逐步上升，而收益 IC 不单调。这说明定价
改善至少部分来自模型容量，尚不能据此解释为经济上可识别的公司类型。

## 当前结论

框架方向正确：它没有要求先知道同行，且把公司画像、市场定价和未来收益
拆成了不同合同。但当前数据量和目标函数下，潜在专家不可识别、软同行不稳定，
收益头也没有超过简单强制基线。该实验保持候选状态，不进入搜参、日报或生产。
