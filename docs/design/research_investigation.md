# 投研调查与建模：先研究，再写作

2026-11-01，本地实现，尚未部署。统一入口是 `research_pipeline`；不新增行业公式库。

## 职责与执行链

原件 / 财报底稿 / 摘要 / 横评 → 调查 Agent → 冻结研究版本 → 初稿 → 审阅 → 定稿。Agent 根据材料识别实际业务、提出问题和模型、补证、写 Python、计算、检验及修正。三轮写作共同读取完整交接，不能另造互不相干的预测数字。

`investigation.py` 使用公共 `ConversationHarness`，通过现有执行器、`research_llm` 容量及费用账本请求模型。默认每次调查最多 16 次模型调用、64 次工具调用、600 秒，与公共 Agent 边界一致，最后一轮只总结。单次最多 65,536 输出 token，包含服务商推理及模型代码；实际请求仍受总预算派发预留约束。初始调查预留三轮写作，审阅返工预留最后一轮；使用公共 `FutureHold` 保守报价，预留不当成消费。

2026-11-02按用户要求增加显式大类调查提醒：实物生产、资源周期、信用资金中介、风险承保与长期保障、持续服务/订阅及混合控股。提醒只提出需要调查的问题，不构成行业枚举、路由、固定业务Schema或公式库；Agent可自行拆分、组合、增补或否定，公式、参数、估值方法仍来自本轮证据与具名假设。历史/预测口径一致性、外部输入扰动与约束真正影响下游也进入通用审查要求，实际业务质量仍以独立验收为准。

调查使用服务商原生 tools / tool_calls。公共传输层保留流式参数分片、工具调用 ID、继续请求所需的服务商上下文及完整 usage；工具消息独立按哈希留档，恢复时验证后读取。无正文的有效工具调用可以继续，空正文且无工具不能被当作调查完成。历史文本协议回执仅兼容读取，不自动重发。

工具提供本轮资料查找、全文分页、公开搜索和获取、模型版本保存、隔离计算、读取结果及显式选定模型。检索摘要只作线索；PDF 全文保留页标记，HTML 不制造页码。读过的完整文本按 SHA 留档，行号对应冻结文本。保存模型校验来源 ID 与行范围；数值是否得到来源支持仍需研究及审阅判断。

全文查找采用不区分大小写的字面关键词，每页 40 个命中、明确 next_offset；同一原件后面的命中不会被首次命中遮蔽。读取工具向模型公开行范围边界，调用时告知剩余工具决策轮次，最后一轮只总结。额度提示不证明 Agent 已合理分配调查和建模时间，实机仍单独验收这一点。研究会话字符窗口默认 1,000,000（可配置到更小），用于保留原生调用上下文和模型代码；每次请求仍经过完整输入的 1M token 及 50 MiB 硬校验和费用预留，不用会话窗口替代实际准入。

`save_model` 接受动态 inputs、assumptions、explanation、evidence 和 Python，不规定行业字段。Agent 负责具名驱动到中间量、利润 / 现金 / 权利 / 每股结果及估值的传导，按业务适用性选择环节。`results.json` 业务字段自由扩展；通用 checks 使用显式 passed 布尔值，charts 使用既有图表格式。程序成功、自设检查通过、独立财务核验是三个不同状态。

## 来源与隔离执行

联网由宿主完成。DataHub 保管原件与内容哈希；公开 HTTPS 获取对每次跳转重新校验并固定公网地址，沿用共享限速及封禁，不发送项目凭据。默认复用 URL 已知原件；`fetch_source(refresh=true)` 取得本次研究的新版本，旧字节保留。记录获取时间、缓存命中及发布日期未核实状态，不能混淆获取和披露日期。

`search_public`默认使用云端已验证可访问的Bing，可显式选择DuckDuckGo；不自动切换、重试或绕过访问验证。候选标题和摘要仅用于发现原件，空结果或超时不代表公司未披露。搜索源的可访问性、查询相关性、原件下载和字段核实是不同验收项。

模型只在 Docker 执行，不自动拉镜像、不退回宿主 Python。容器无网络、只读根目录、非 root、无 capabilities、禁止新增权限，限制 CPU / 内存 / PID / 时间。只挂载该模型输入和输出目录，不挂载项目源码、凭据或整个资料库。镜像 ID、代码及输入哈希进入回执。默认镜像仅 Python 标准库，不允许模型安装依赖。

宿主限制输出文件数量及大小，拒绝链接、设备和非有限 JSON 数字。取消 / 超时停止容器；清理无法确认保存 unknown 和容器名。沙箱缺失保存 unavailable；不能用预想结果填回执。安全检查拒绝的输出不复制进交付，原执行目录与原因保留。

## 版本、恢复与交接

每个研究保存底稿、来源目录、原件、冻结文本、模型代码 / 输入 / 依据、计算结果、工具序列、模型请求回执、研究说明和哈希清单。handoff.md 包含选定模型的完整输入、代码、实际结果与来源。未建成模型、检查失败、预算及上限问题写入宿主状态；可保存多个模型版本，必须显式 select_model。

请求传输的`execution/`目录可能在研究超时后继续追加事件及结算，保留在执行审计范围，不纳入研究冻结文件清单。来源、模型输入、沙箱执行回执及实际结果仍逐项冻结；排除活动传输日志不能放宽计算产物完整性。已因旧清单失效的版本保留原样，不重写旧哈希。

初始调查没有选定实际计算模型时，保存阶段成果和缺口，不开始三轮写作，禁止以手工“条件算例”补齐预测、IRR 或最高买价。审阅返工未形成可用模型时，保留已有审阅及返工记录，不进入定稿。选中但业务检查失败的模型仍保留失败状态，不能把程序成功当作财务正确。

起始消息与工具序列持久化。恢复重放已记录结果，不因新增来源改变早先请求；成功 / 失败 / unknown attempt 均不自动再发。已冻结 partial 保留原状态，恢复只继续未发送的后续工作；重新调查使用显式新版本。

图表来自选定程序输出 charts，并将实际 PNG 交接给后两轮。审阅必须给出 research-rework 布尔决策及问题；缺失 / 损坏决策保留 partial。实质修改只允许一次 review_rework，读取旧交接与审查问题，重算、产生新冻结版本和新图片供定稿；不增加第四轮写作，不声称第二轮已审查新结果。未解决事项继续披露。

宿主校验完整性、执行回执与图表出处，不能自动证明所有经济解释正确。complete 是执行状态，financial_validation=not_independently_verified 独立保留。

本地交付保留完整冻结包。Bot 附件按验证后的来源 / 输入 / 代码 / 结果白名单导出可复算子集，并提供 reproducibility.json 哈希清单；不导出请求和工具诊断日志，也不为脱敏而改写计算 JSON 的业务字段或破坏输入哈希。既有附件大小及原会话权限限制继续适用。

已有有效报告按原身份复用，不因 prompt 升级失效。CLI --reinvestigate、Python ResearchSpec(reinvestigate=True) 和 Bot prepare 同名布尔参数建立新研究身份，共用授权合同和总预算，复用原件 / 底稿，保留旧报告及旧 attempt。无 --paid 的计划不联网、不调用模型。

## 验收案例：只供评估，不作为运行规则

| 案例 | 资料与必须核查的传导 / 反例 |
|---|---|
| 核电 | 机组、投产、利用小时、厂用电、电价、成本、项目权益及建设资金。改变投产时间须传到电量 / 利润 / 资金缺口；增发和注入同时改变利润与股份；区分并表少数股东和权益法，不能重复乘权益。 |
| 石油 | 产销结构、实现价格、桶油成本、资本开支及储量约束。价格 / 成本变化传到利润和现金；油气单位、不同成本口径不能混用，税费与债务不重复。 |
| 煤炭 | 产销量、长协 / 现货、吨煤成本、运销及权益。组合变化不能被统一利润率掩盖；量价成本、集团归属及融资结果闭合。 |
| 银行 | 生息资产、付息负债、收益率、资金成本、信用成本及资本约束。重定价传到净利息收入；信用损失、分红和补资本传到权益与每股结果，不用工业 FCF 补桥。 |
| 财险 | 业务组合、赚取保费、赔付 / 费用、再保险、准备金与投资。综合成本率保持一致分母；准备金和再保险不重复，承保与投资分别解释。 |
| 寿险 | 合同服务、利润释放、投资 / 保险负债、业务结构及偿付约束。依据资料选择机制，不套财险综合成本率；区分当期利润、权益变化和可分配能力。 |
| 订阅软件 | 未写任何专属运行规则。提供客户分组、留存 / 流失、价格、合同、递延收入、获客与股权激励材料，由 Agent 自选 cohort / 确认等结构；收入、收款、费用与摊薄连贯。 |
| 混合业务 | 分部不同机制、内部交易、共同费用、控制权和净债务。自主拆分并选择 SOTP 或其他适用方法；消除内部交易，企业 / 权益价值口径一致，不重复扣债或乘权益。 |

真实验收需加入隐藏行业标签、同业不同机制、冲突来源及反例，观察模型是否随证据变化，不能只检查 prompt 命中。对选定模型改变时点、价格、成本、融资或注入，逐项核对中间量与最终结果。历史残差、敏感性及反例检查须有经济解释，恒真检查和自报 passed 不能算通过。

## 当前验收边界

离线测试使用真实编排 / 持久化 / 哈希 / 渲染，模型响应与容器 IO 用明确标注的合成夹具；验证版本、旧报告保护、预算预留、工具重放、来源冲突、缺资料、沙箱缺失、异常输出、取消及超时。它们不证明上表业务能力。
