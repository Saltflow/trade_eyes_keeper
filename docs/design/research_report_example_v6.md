# 通用研究排版示例：结构来自约定，事实来自本轮输入

本文件只演示布局和公式。对象数量、公司名称、业务、行业、比较组、参照角色、实际年份、价格和预测参数均来自本轮材料与用户任务；示例不提供任何真实公司的事实或投资结论。不要求每轮必须有参照组，不把任何真实公司列为固定样本。

## 一、先回答价格和回报问题

开头给结论成立的经营/资本/分配/终值条件及最重要反证。多家公司用同指标横比；单公司用自身实际历史、业务分部及情景比较。不逐家公司重复完整章节，不凭对象数量套固定角色。

## 二、规模、权利与行情

共同尺度表：指标/单位为行，本轮实际对象为列。展示适用的收入/利润、资产/普通股权益、现金/融资及每股指标，再列报价日、未复权价格、股类/币种和已知股数/市值。财务日与行情日分别写；账面权益不是市值，不从价格猜股数。没有行情的对象局部写未取得，不取消其他已知经营事实。

## 三、同指标、同时间、同分母

历史表以“指标/单位｜本轮公司｜本轮实际年度各列”组织，每个指标内公司相邻。字段局部缺失只影响该单元，图用null；没有提供的年份不增造空列。每家公司自己的共同可得基年=100，原数同表保留，CAGR写实际端点及间隔。原报/重述、时点/期间/平均、集团/母公司分组说明，不偷偷合并。

每个主题按“横向发现或历史发现→相邻表→同指标图→经济机制→定价影响与反证”展开。行业专属分母随实际业务选择，不能因都用百分号而把不同指标混画。

## 四、五年预测先给假设台账

假设表按“实际适用变量｜历史依据｜保守｜基准｜乐观｜限制”组织。历史之后的未来五个完整财年标E，财务基期与行情日有时间差时解释现金权利和折现时钟。

逐年表按“指标/单位｜本轮公司/情景｜未来五年各列”，公司相邻。列收入/盈利、普通股利润/EPS、股数、普通股权益/BVPS/ROE、必要再投入或资本留存、潜在股权现金与实际情景DPS。不同业务现金方法不同，缺关键调整不默认为零。权益、利润和分配要滚动一致，不从收入CAGR自动得到所有预测。

## 五、从现金流算到买价

估值表在同一情景、同一hurdle下并列实际对象：价格/日期、正常化利润与现金收益率、未来逐次DPS、期末每股价值、IRR、各hurdle最高买价/安全边际、终值贡献。退出倍数或永续法只选一种主终值，不能相加；留存和已分配现金只计一次。

在明确t=1..5的年度分配简化模型下：

- 现金流为[-P0,DPS1,DPS2,DPS3,DPS4,DPS5+P5]；IRR使净现值为0。
- Pmax(h)=Σ[DPS_t/(1+h)^t]+P5/(1+h)^5。
- 安全边际=1−P0/Pmax(h)，分母为Pmax；终值贡献=(P5折现)/Pmax(h)。
- 每股权益滚动要包含利润、分配及已说明的OCI/股本变化；ROE=对应普通股利润/平均普通股权益。

这些是公式，不是本轮参数；hurdle未指定时用具名敏感性并明确为研究取值。简化年度模型不冒充按实际支付日期的XIRR。反解条件固定其他同组假设，说明现价要求什么增长、盈利、资本效率、分配或退出条件。

## 六、图表靠近论点

选择支持实际问题的图：经营/每股历史、资本回报、适用现金桥接、资本配置、预测、hurdle与终值敏感性。公司图例和实际年份按输入生成；同指标同轴，必要分面共用尺度。前两轮给chart原数，第三轮只引用已生成、实际收到的PNG。不固定图数，不为画图补数。

## 七、给出可以证伪的条件

反证表：当前假设｜可观察触发条件｜对利润/现金/资本/每股价值的传导｜重看时点。触发变量来自本轮实际业务，不能沿用不相关行业的风险清单。最后列关键未定位字段与口径、对定价方向的影响及实际核验边界；不能把未定位写成原文未披露。
