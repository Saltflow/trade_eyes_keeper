# 正式研究排版示例 v5：实际历史 → 五年情景 → 最新已知价回报

> 示例用于形式验收，不是模型研究或投资结论。给三年数据就用三年，给七年就用七年；七年是目标资料量，不是显示窗口。不为未提供的年份补空列或拉长坐标轴。虚构U只演示计算，不属于三家公司。

## 一、先回答支付这个价格得到什么

以估值问题为主线。工程两家深入横比，白酒作机制参照。开头给相对判断、成立条件及反证，再给共同规模、实际历史、预测、现金和定价。不能只给历史诊断；缺参数时给条件式结果并明示依赖。

## 二、共同尺度与最新已知价

同一指标为行、公司为列：收入/利润、现金/受限/债务、普通股权益与权利、EPS/BVPS/ROE，以及本轮行情快照。报价日与财务日分别列，价格使用未复权口径；每家公司日期分别显示，不假称实时或同日。市值和股数缺失不从价格猜测。旧底稿“行情未提供”不覆盖本轮新快照；手动指定快照优先，不混入自动行情。

### 归一化单位公司：纯虚构形式算例，不属于三家公司

为验证预测→现金→每股→终值→IRR→hurdle展示，单独设置单位公司U。金额为虚构单位，价格为单位/股，股数10、基期收入100、普通股权益100、假定买价10、市值100；均非实际行情。无债务、无少数股东/其他权益，净融资0。保守/基准/乐观增长分别0%/5%/10%，净利率8%/10%/12%；不是历史估计或投资建议。

三情景折旧=收入2%，资本投入=收入3%，非现金营运资本=收入20%，因此增量占款=增量收入20%；期末营运资本及固定资产由这套假设滚动。CFO=利润+折旧−增量营运资本；FCFE=CFO−资本投入+净融资，不再重复扣占款。FCFE全部假定年末分红，股数不变，无回购。普通股权益期末=期初+利润−分红，ROE使用期初期末平均权益。无期初多余现金；期末价值不再叠加已分出的FCFE。

退出采用第五年EPS×10倍PE（主观敏感性假设），不是永续增长估值；不再另外加永续终值。hurdle为8%/10%/12%敏感性，不是用户指定门槛。所有未来值标E；实际公司预测仍未验收。

## 八、反证与重看

对工程两家，应检验订单转收入、项目利润率、占款释放、正常投入与融资约束；对白酒参照，应检验库存/预收与分红现金。预测收入增加但营运资本消耗更快、利润率回落或退出估值下降，都可推翻回报结论。真实公司缺价格/权利/假设时继续给条件表达，不给当前便宜或达标排名。形式样例不能证明真实模型会作出这些判断。
