# 单公司摘要七问的原始研究目标

本文件保留旧研究说明中的七问原文，供摘要合同回归核对。旧执行skill及其不存在的脚本入口已清理；当前研究使用financial_pipeline和research_report显式流程。本文件不提供执行、付费或发布权限。

# 持续同行研究

先按[回报与风险主线](../guide/research_report.md)用长期面板形成正常化假设与现价隐含回报的初步判断，再围绕决定性问题读完整MD&A和附注：观察差异 → 计算拆解 → 对照公司解释 → 替代解释和反证 → 判断持续性 → 更新情景回报与风险。每次工具续轮沿用会话，不重启完整决策。

七个问题用于检验回报与风险论证，按重要性合并、排序，并在需要处穿插行业专题：

1. 公司怎样赚钱，产品、客户与单位经济的成本锚是什么？
2. 实际历史中利润、资本与每股价值怎样增长或损耗？
3. 最近经营方向发生什么变化，是行业共因还是公司差异？
4. 利润如何变成现金，正常化现金需要什么恢复和投入假设？
5. 现金投向哪里，再投资、分红和回购能否延续价值创造？
6. 哪些现金与增长对应当前价格，价值范围和安全边际怎样？
7. 哪些具体反证会推翻判断，何时重看？

利润桥分析量、价、结构、成本、税费；现金桥分析调节表与营运资本；每股桥分析股数、分派和账面变化。解释不完的金额保留残差。管理层解释需要金额、同行或后续兑现支持，因果关系可保留为待验证假设。

正常化不是平均数，也不是下季度自动实现。用近期利润、可持续现金转化、完整投入和行业状态建立压力/工作/恢复路径，展示恢复延后的影响。区分经营现金、股东归属近似和实际可分派金额。没有维护Capex依据时，完整现金Capex可作为保守起点，按证据提出不同范围。

主估值含资金收益时不再另加相同现金资产。现金释放单列，扣去放弃的税后现金收益后加一次本金，明确时点、经营缓冲、客户资金、监管和分派权利。增长受再投资与资本回报约束；终值增长根据情景说明依据。不给投资人设定默认要求回报，列示不同正常化假设的现价隐含回报及终值、折现率和恢复时间的价值敏感性，不用历史PE低分位证明错价。

风险写明公司暴露、金额或方向、传导至盈利/现金/价值的路径、证据和trigger。宏观标签本身没有解释力；不用“基本合理”等含糊词代替状态。允许观察、放弃或尚不能区分，但给出实质分析。

已有原文和已经进入会话是两种状态。先看`management_context.coverage`及完整章节；初始输入按证据策略投递最近年报和最新期间的MD&A。较早年份的转折、长期因果或同行承诺兑现需要回查对应完整章节，不能因为目录存在就声称已阅读。原文送达不能证明理解；报告应说明解释如何支持或反驳现金假设。未取得或未研究的部分限制相关判断，不能编造管理层解释。

普通股现金从经营现金或明确归属的利润开始，经营运资本、维护与增长投入、现金税费、融资成本及普通股权利桥接。已经归母的利润不得再次乘少数股东归属比例；集团投入需要分配时单独调整该投入。折旧和特许权摊销是检查投入需求的线索，不能直接断言等于维护现金。用转换率、维护投入或票息估计时分别登记为`assumption`，列历史金额、原文解释和反证；用代码计算结果，不能先写终值金额再补方法。跨期资本结构采用明确pro forma桥接，不能悄悄把中期资本余额当上年实际分配。
